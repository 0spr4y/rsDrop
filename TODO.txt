rsDrop release checklist

Dependencies
- [ ] Resolve RUSTSEC-2025-0134: rustls-pemfile 2.2.0 is unmaintained (via axum-server 0.7.3). The last audit reported no vulnerability findings and no fixed upgrade for this warning. Investigate an upstream update or alternative PEM loader and test TLS compatibility.
  https://rustsec.org/advisories/RUSTSEC-2025-0134
- [ ] Run cargo audit in CI and before releases; build releases with --locked.

Deployment
- [ ] Require valid HTTPS. With a TLS reverse proxy, keep the backend port private and configure HSTS at the proxy.
- [ ] Enable --create-token for restricted creation; protect startup logs containing the token.
- [ ] Add rate limits for creation, failed authentication, and retrieval, plus proxy connection limits and request/header timeouts.
- [ ] Set container memory/CPU/PID limits, a read-only filesystem, dropped capabilities, and no-new-privileges. Mount TLS keys at runtime.
- [ ] Restrict log access and retention; review share-ID logging and avoid proxy request-body logging.
- [ ] Verify host swap/hibernation, core-dump, and crash-collector policies as described in Readme.txt.

Tests
- [ ] Extend existing authentication-ordering, expiration-boundary, and ID-validation tests to cover successful creation/retrieval, body and decoded-size limits, invalid nonces, capacity, concurrent requests, and security headers on errors.
- [ ] Test browser encryption/decryption, tampered ciphertext, malformed/missing key fragments, Unicode size boundaries, and HTTPS through the proxy.
